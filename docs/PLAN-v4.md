## ملاحظات
- **إعادة استعمال:** «برج سبير» تستعمل نفس الجسر (`addons/spir`) ونفس الغلاف — نسخة واحدة مشتركة بـ `games/_godot/` بدل نسخة لكل لعبة.
- **المحرك المصغّر اختياري:** إذا ما موجود بالإصدار، `packs.yml` يستعمل القالب الرسمي — ما يوقف شي.
- **التحديث للأجهزة:** حزمة «تجنّب الوحوش» تصير `version: 2` (ملف أصغر)، والتطبيق يمسح النسخة القديمة تلقائياً بعد تنزيل الجديدة.

### لعبة Godot جديدة — الخطوات
1. `games/<id>/godot/` (project.godot + main.tscn + main.gd، انسخ export_presets.cfg من لعبة موجودة) و`games/<id>/art.mts` و`game.json` (`engine: godot`, `pack.type: download`).
2. `node --experimental-strip-types games/_godot/make-art.mts <id>` ← الصور.
3. `GODOT=… GODOT_TEMPLATE=…/godot-web-2d-4.4.1-b.zip npm run pack:godot <id>` ← يحدّث `pack.bytes`.
4. ارفع، وشغّل workflow «Game Packs».
