# خطة بناء «عالم سبير» — الإصدار 0.2

> الهدف: نقلة كاملة من «قائمة ألعاب بأشكال بسيطة» إلى **عالم واحد بشخصية**، فيه ألعاب بجودة المتجر، وسبب يرجّع الطفل كل يوم.

## 0. قرارات أساسية

| القرار | الاختيار | السبب |
|---|---|---|
| الشخصية | **سبير**: بزون برتقالي مغامر، وشاح أزرق، عيون كبيرة | الشخصية تربط كل شي، والبزون موجود أصلاً بأشهر لعبتين |
| محرك الرسم | **PixiJS 8.22 (WebGL)** داخل نفس نظام الألعاب المعزولة (HTML + الجسر) | sprites وجزيئات و60 إطار، ونفس الملف يشتغل بالأندرويد والويب |
| الرسوميات | **رسوم متجهة (SVG) أكتبها بالكود** بدليل أسلوب واحد، وتتحوّل لصور داخل اللعبة بدقة الشاشة | ماكو رسام هسه، وهذا يعطي شكل كرتوني ناعم (تظليل، حدود، لمعة) بدون مشاكل رخص، وحادة بكل الشاشات. ينقدر يتبدل برسوم رسام بعدين بدون تغيير الألعاب |
| تحريك الشخصيات | **تحريك القطع (cutout)**: الراس، الأذنين، الذيل، العيون قطع منفصلة تتحرك بالكود (رمش، تنفّس، فرح، فزع) | نفس فكرة Spine بدون رخصة ولا أدوات خارجية |
| الخط | **Baloo Bhaijaan 2** (عربي مدوّر للأطفال، رخصة OFL) للكل، و**Lalezar** للعناوين الكبيرة | مرح ومقروء للأطفال، ومضمّن داخل الألعاب حتى يشتغل بدون نت |
| الصوت | مؤثرات مولّدة بـ Web Audio بشكل أغنى (طبقات، صدى) + موسيقى خلفية خفيفة مولّدة لكل مكان | بدون ملفات ولا رخص؛ الصوت البشري العربي ← مقترح لاحق |
| الخريطة والبيت | **مشاهد Pixi** داخل التطبيق بنفس الجسر (مو شاشات React Native) | نفس أسلوب الرسم والحركة بالضبط، وبدون مكتبات أصلية جديدة (أقل مخاطرة على بناء الـ APK) |
| واجهة التطبيق | هوية جديدة: ألوان السماء والشمس، أزرار «حلوى» منفوخة، خط Baloo | ثيمات كرة القدم ما تناسب عالم ألعاب |
| الألعاب القديمة | تبقى بـ **«صالة الكلاسيكيات»** على الخريطة | ما نحذف شي يشتغل، والأولوية للألعاب الرئيسية |

## 1. دليل الأسلوب (Style Guide)

- **الألوان:** سماء `#4FB8FF`، شمس `#FFC93C`، مرجاني `#FF6B5B`، ورقي `#3DD68C`، عنبي `#7B5CFF`، حبر `#1E1B3A`، كريمي `#FFF7EA`.
- **الأشكال:** زوايا مدوّرة كبيرة، حد داكن ناعم (حبر 85%)، تدرّج من فوق لجوه، ولمعة بيضاء صغيرة فوق-يسار، وظل ناعم تحت كل شي.
- **العيون:** كبيرة بلمعتين، تتحرك وترمش.
- **الحركة:** كل شي «ينط» (back easing)، الضغط يضغط الشي (squash)، والنجاح فيه جزيئات ونجوم.

## 2. المعمارية

```
packages/
  spir-art/       ← رسوم SVG بالكود: سبير وتعابيره، بزازين بالألوان، قطع، بلاطات، خلفيات، أزرار، نجوم
  spir-engine/    ← فوق Pixi: تهيئة وتكبير، مشاهد، tween، جزيئات، اهتزاز، صوت وموسيقى، نص عربي، أزرار، SVG→Texture
  spir-kit/       ← (القديم) للكلاسيكيات — يبقى
games/
  world/          ← خريطة «عالم سبير» (مشهد)
  house/          ← «بيت سبير» (مشهد): تزيين بالعملات
  drop-cat/ trap-cat/ merge/ blocks/ connect4/  ← الألعاب الرئيسية بالمحرك الجديد
  (الباقي)        ← الكلاسيكيات
```

**توسعة الجسر:**
- من التطبيق: `{type:'state', data}` — بيانات الخريطة/البيت (نجوم، عملات، أغراض).
- من المشهد: `{type:'open', target}` لفتح لعبة أو مكان، و`{type:'house', data}` لحفظ البيت والمشتريات.

## 3. الألعاب الرئيسية الخمس

| اللعبة | التطوير |
|---|---|
| **نزّل البزون** (النموذج الأول) | بزازين متحركة (تفزع، تنزلق، تطيح وتفرح)، قطع خشب، فتحات بلمعة، 4 عوالم بخلفيات، **120 مرحلة** (40 لكل صعوبة) محلولة بالمحلّل، تراجع وتلميح، مؤقت بالصعب |
| **حاصر البزون** | أرض عشب سداسية، شجيرات تنمو بدل الدوائر الزرقاء، سبير يتلفّت ويفكر، ويهرب بقفزة |
| **دمج المخلوقات** | 11 مخلوق «سبيرات» يكبرون بالدمج (لكل واحد لون وشكل وقبعة)، بدل الأرقام |
| **بلوكات الحلوى** | بلوكات لامعة مثل الحلوى، انفجارات جزيئات، كومبو |
| **أربعة بخط** | قطع بوجوه بزازين ضد جراوي، طاولة خشب، احتفال بالفوز |

## 4. الدافع للرجوع (Meta)

- **الملصقات:** كل فوز بلعبة رئيسية يعطي فرصة ملصق (36 ملصق: بزازين وأغراض)، والألبوم يتعبّى.
- **بيت سبير:** غرفة يزيّنها الطفل بأغراض يشتريها بالعملات (أثاث، ألعاب، نباتات، ملابس لسبير) — 24 غرض.
- **تحدّي العائلة الأسبوعي:** ترتيب نجوم الأسبوع بين أفراد العائلة.
- **الخريطة:** الأماكن تنفتح بالنجوم (مثلاً «بلوكات الحلوى» تنفتح بـ 10 نجوم).

## 5. واجهة التطبيق

- الأقسام: **العالم** (الخريطة) · **البيت** · **الألبوم** (ملصقات + أوسمة + ترتيب العائلة) · **حسابي**.
- الشاشات القديمة (منو يلعب، وضع الأهل، التحديث، الخصوصية) تبقى بالهوية الجديدة.
- شاشة اللعب: شريط علوي بالهوية الجديدة، ونافذة النهاية فيها سبير يحتفل والملصق اللي ربحته.

## 6. ترتيب التنفيذ

1. المحرك + الرسوم + الخط (الأساس).
2. **نزّل البزون** بالجودة النهائية ← أراجع اللقطات وأصلّح قبل ما أكمل.
3. الخريطة.
4. حاصر البزون، دمج المخلوقات، بلوكات الحلوى، أربعة بخط.
5. الملصقات + بيت سبير + تحدّي العائلة.
6. واجهة التطبيق بالهوية الجديدة.
7. اختبارات، تجربة كاملة بالمتصفح، توثيق، الإصدار **0.2.0**.

## 7. معايير الجودة (قبل ما أگول «خلص»)

- كل لعبة: منطق مفحوص بالاختبارات + تجربة لعب فعلية بالمتصفح للنهاية + لقطات أراجعها بعيني.
- 60 إطار على الويب، وحجم كل لعبة أقل من 1.5MB.
- ماكو أخطاء بالـ console، والأنواع والتنسيق نظيفين.
