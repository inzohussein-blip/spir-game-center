# خطة الإصدار 0.3 — محركات ألعاب إضافية

> الهدف: المنصة تقبل ألعاب من **أي محرك يصدّر للويب**، بنفس الجسر ونفس قواعد الأمان والرخص،
> ويّا لعبة **Phaser** كبيرة ولعبة **Godot** مفتوحة المصدر كأول تطبيق للفكرة.

## 1. التنظيم: «حزمة» واحدة لكل لعبة

كل لعبة — مهما كان محركها — تتحول لـ **ملف HTML واحد مستقل** (الكود والصور والأصوات وملفات wasm داخله).
هذا يخلي التشغيل نفسه بكل مكان: WebView بالأندرويد، iframe بالويب، وبدون نت.

| النوع | مثال | وين يعيش |
|---|---|---|
| **داخل التطبيق** (`"pack": "bundled"`) | ألعابنا + Phaser | ينبني ويّا التطبيق (assets) |
| **تنزل عند الطلب** (`"pack": "download"`) | Godot (عشرات الميغات) | ملف بإصدار GitHub؛ التطبيق ينزّله مرة وحدة ويحفظه بالجهاز |

## 2. حقول جديدة بـ `game.json`

```json
{
  "engine": "spir | spir-kit | phaser | godot",
  "pack": "bundled | download",
  "license": "MIT",
  "assets": [{ "what": "الرسوم", "license": "CC0-1.0", "by": "Kenney" }],
  "credits": "نص يطلع بصفحة اللعبة إذا الرخصة تطلب ذكر الاسم"
}
```

سكربت البناء يرفض أي لعبة: رخصة كود أو أصول غير مقبولة، أصول برخصة CC-BY بدون `credits`، أو تحمّل شي من النت.

## 3. الجسر لكل محرك

| المحرك | الطريقة |
|---|---|
| spir / spir-kit / Phaser | `send()` من `packages/spir-kit/sdk.ts` مباشرة |
| Godot | `addons/spir/spir.gd`: يستعمل `JavaScriptBridge` حتى يرسل `ready / hud / complete / over` ويستلم `start / pause / resume / sound` |

**الأمان:** ألعاب WebAssembly (Godot) ياخذ ملفها `'wasm-unsafe-eval'` بسياسة الأمان — بملفها بس، مو بالتطبيق.

## 4. التنزيل عند الطلب

- صفحة اللعبة: «نزّل اللعبة (32 ميغا)» ← شريط تقدّم ← «العب». و«امسح من الجهاز» يرجّع المساحة.
- الملف ينحفظ بـ `documentDirectory/packs/<id>-<version>.html` ويشتغل بدون نت بعدها.
- مصدر الملف: إصدار GitHub ثابت `packs` (يتحدث بـ workflow خاص)، والويب ياخذه وقت البناء ويحطه بالموقع.
